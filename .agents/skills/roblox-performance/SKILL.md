# Roblox performance

Treat mobile and lower-end devices as first-class targets. Prefer event-driven work over per-frame polling, bound loops and remote frequency, clean up connections, and limit replicated instances and physics. Use Studio device simulation and 6–8 client sessions for load checks when Studio is available; do not infer performance from portable tests alone.
